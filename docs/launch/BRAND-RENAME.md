# MyPropertyVisit brand change

Approved 10 November 2026. MyPropertyVisit is the selected name. Tagline: Every visit. Every detail. iOS store subtitle: Compass photos & room details.

## Updated

App display names, Home and Settings text, accessibility labels, camera/Photos permission copy, light/dark launch artwork, sharing labels, new export filenames and Android Gallery destinations, project names, source/readme paths, website wordmark/page titles and privacy/support/store documentation.

The iOS Xcode project, shared scheme and app target are MyPropertyVisit. Android Studio root project is MyPropertyVisit. The GitHub repositories are now 1Bullzeye1/MyPropertyVisit and 1Bullzeye1/MyPropertyVisit_android; local remotes point to those names. Local checkouts are MyPropertyVisit, MyPropertyVisit-Android and MyPropertyVisit-Website under Documents/ChatGPT.

## Compatibility

The iOS bundle identifier remains com.infinity-propview.app. Android application ID remains com.ganesham.app. Existing preferences, SQLite filename, media directories and metadata identifiers are retained. Legacy lowercase preference/database keys are intentional and must not be globally replaced without a tested migration. Existing Gallery exports and historical Git commits/tags are not rewritten; new exports use MyPropertyVisit naming.

The house-and-compass glyph and purple themes continue under the new name. Light/dark launch text is generated from editable SVGs in the iOS Branding directory. The Android launch assets use the same rendered artwork.
