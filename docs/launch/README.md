# MyPropertyVisit Android launch documentation

Prepared 10 November 2026. Current offline functionality is the launch scope: local properties/profile, silent camera videos, compass JPEGs/new MP4s, visits, room dimensions/notes, full-screen photos, sharing and saving individual/multiple/all media to Gallery. iOS USD 4.99 pricing has been agreed; Android pricing is **not yet decided**. No iOS purchase entitlement is promised for Android.
